# Calendar visibility formatting update

This build improves the First Chair Calendar tab so the month view is easier to read.

Changes:
- Calendar day cells now stay light/white instead of inheriting the dark primary button styling.
- Selected day uses a clear blue outline and light blue background.
- Today uses a light amber highlight.
- Blank leading/trailing cells use a light patterned background instead of dark empty blocks.
- Event pills use readable colors and borders.
- Month calendar is wider and taller on large screens.
- Calendar side panels are slightly tighter so the month grid gets more room.
