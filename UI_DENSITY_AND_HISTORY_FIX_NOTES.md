# UI Density and Chat History Fix

This build adjusts the ChatGPT-style UI after visual testing:

- Recent chat items now stay readable instead of inheriting the global dark button style.
- Empty or generic chat titles now show a fallback label such as `Chat from Sep 7, 2026`.
- The main workspace uses the full available width instead of being capped in the center of large screens.
- The chat card is taller and wider with less unused whitespace.
- The login page panels are larger, centered, and more balanced on wide displays.
- The chat controls sidebar is tightened so more recent chat history is visible.
