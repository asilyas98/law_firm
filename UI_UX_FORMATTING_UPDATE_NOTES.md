# UI/UX and Legal Formatting Update

This build improves the app's display and export formatting for legal drafts and chatbot answers.

## Added

- Modernized visual design with a cleaner ChatGPT-style workspace.
- Improved chat card, sticky chat header, cleaner message bubbles, and polished composer.
- Rich legal-document preview renderer for generated output and assistant answers.
- Markdown headings, bold text, bullet lists, numbered lists, field rows, and tables now render visually in the app.
- DOCX exports now include styled headings, colored accents, bold text, bullet/numbered lists, and Markdown tables.
- PDF exports now include a professional header bar, styled headings, footer page numbers, and pending-attorney-review footer language.
- Chat and document generation prompts now ask the model to produce polished Markdown instead of plain text walls.

## Best practice

Ask the chatbot or document generator to produce legal drafts using headings and tables, for example:

"Draft this as a polished legal document with headings, bold key terms, a fact table, numbered arguments, and a signature block."
