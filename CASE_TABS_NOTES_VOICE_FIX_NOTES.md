# Case Tabs + Notes Voice Fix

## Changes
- Added microphone dictation support inside the selected case Notes tab.
- Case notes are saved back onto the selected local case record as speech text is captured.
- Case workspace tabs (Intake, Info, Calendar, Documents, Tasks, Notes, Billing, Workflows, Tools) are now hidden until a case is created and selected.
- When no case is selected, the Cases screen shows the case list and intake creation form only.
- Creating a case opens its case-specific workspace tabs.
- Selecting a case loads that case's intake info and notes into the tabbed workspace.

## Browser Note
Voice dictation uses the browser Web Speech API. It works best in Chrome or Edge over HTTPS and requires the user to allow microphone permission.
